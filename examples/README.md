# Два примера из каталога

Входные JSON подготовлены вручную по записям `docs/feed.xml` и страницам заказчика,
проверенным 4 ноября 2026 года. Это исходные данные, а не результаты генерации.
Текст сокращён и переформулирован; неоднозначные свойства не добавлялись.

| Файл | Товар | Код товара | Источник |
|---|---|---|---|
| `mk110.json` | ОВЕН МК110-224.8Д.4Р [М01] | 63483 | https://www.souz-pribor.ru/product/mk110-8d-4r/ |
| `pm01.json` | ОВЕН ПМ01-24.АВ | 73534 | https://www.souz-pribor.ru/product/pm01/ |

У МК110 число каналов, интерфейс и защита взяты из таблицы характеристик,
назначение — из описания. На странице сравниваются версии: список протоколов
не переносился в пример из-за различий между версиями.

У ПМ01 диапазон питания взят из строки, явно относящейся к ПМ01-24.АВ,
интерфейсы — из таблицы модификаций. Описание серии вручную отобрано как исходный
контекст; автоматическое дообогащение консервативнее и не переносит весь текст серии.

Для демонстрации выберите JSON в UI, модель и сформируйте карточку. Проверьте
предупреждения, длины, соответствие исполнения и сохраняйте рабочие выгрузки в
`results/` как `mk110.json` / `pm01.json` либо Markdown. В JSON останутся фактические
провайдер и модель, число попыток, источники и замечания проверки.

В `reference_results/` сохранены два проверенных по формату результата Codex CLI
(`gpt-6.1-sol`) для настоящих товаров — `mk110` и `pm01`, каждый в JSON и Markdown.
Это черновики для демонстрации по ТЗ, их всё равно нужно проверять перед публикацией.
Папка хранится в Git; скрипт проверки не обновляет эти файлы автоматически.

`results/` предназначена для рабочих прогонов и исключена из Git. Скрипт
`scripts/validate_codex.py` сохраняет туда ответы, а в `summary.json` — статусы
и длительность проверок. Искусственные сценарии явно помечаются в результатах;
подставные ответы автоматических тестов в эти файлы не записываются.

В папке `scenarios/` находятся отдельные искусственные примеры для вкладки
«Примеры сценариев». Они не описывают реальные товары: локальные HTML-страницы
помечены как демонстрационные и служат для воспроизводимых проверок конфликтов,
дообогащения и различий между исполнениями.
